## Descripción del proyecto
Este proyecto fue desarrollado utilizando **Streamlit** como parte del curso de Fundamentos de Programación.  
El objetivo es aplicar conceptos básicos de programación en Python mediante una aplicación interactiva.

La aplicación permite realizar diferentes ejercicios relacionados con análisis de datos, finanzas y estructuras de programación.

---

## Funcionalidades principales

### 1. Flujo de caja
Permite registrar ingresos y gastos, mostrando automáticamente:
- Total de ingresos
- Total de gastos
- Saldo final
- Estado del flujo (positivo, negativo o equilibrado)

---

### 2. Registro de productos
Utiliza **NumPy y Pandas** para:
- Registrar productos
- Guardar categoría, precio y cantidad
- Calcular el total por producto
- Mostrar inventario en una tabla

---

### 3. Cálculo de margen neto
Calcula indicadores financieros como:
- Utilidad bruta
- Utilidad neta
- Margen neto en porcentaje

---

### 4. Evaluación de proyectos
Evalúa proyectos de inversión usando:
- VPN (Valor Presente Neto)
- ROI
- Payback
- Recomendación final de inversión

---
